# Changelog

## v1.0.0 - 2026-05-24

- Windows tray app with configurable eye-break schedule.
- Full-screen break overlay across all displays with Casual, Balanced, and Hardcore modes.
- Snooze limits, pause actions, long-break cadence, and pre-break warning.
- Idle, fullscreen, meeting, and office-hours suppression.
- Blink reminders, onboarding, Today counters, visual aids, and ambient audio.
- Theme switching, auto-launch, NSIS installer, and downloads page.

Known limitations:

- Windows only.
- Manual updates only.
- English only.
- Installer is unsigned unless a code signing certificate is configured locally.
